# 카톡 조작기

실제 카카오톡과 똑같이 생긴 가짜 대화를 만들고 저장/불러오는 장난용 도구입니다.

- 로그인 없이 넷플릭스 프로필처럼 "내 프로필"을 골라서 시작합니다.
- 프로필마다 **아이폰 / 안드로이드** 카톡 디자인을 선택합니다 (대화목록·대화방·상태바·입력창이 해당 기기 모양으로 바뀜).
- 프로필마다 여러 개의 대화방(상대 이름, 프로필 사진 또는 기본 프로필 색)을 만들 수 있습니다.
- 대화방에서 텍스트/사진/날짜 구분선을 내 메시지 또는 상대 메시지로 추가하고, 말풍선을 탭해서 수정·삭제·순서 변경할 수 있습니다.
- 같은 사람이 같은 분에 보낸 메시지는 실제 카톡처럼 묶여서(프로필·이름·꼬리는 첫 말풍선에만, 시간은 마지막에만) 표시됩니다.
- 대화방 설정: 상태바 시계/배터리, 글자 크기, 대화목록 안읽음 수.
- **캡처 모드**: 편집 UI를 전부 숨기고 전체화면(안드로이드 크롬은 실제 상태바·주소창까지 숨김)으로 보여줍니다. 화면을 탭하면 "PNG로 저장 / 종료" 버튼이 잠깐 나타납니다.
- **PNG 저장**: 실제 휴대폰 스크린샷과 같은 해상도로 저장합니다 (안드로이드 1080×2228, 아이폰 1179×2556).

화면 치수·색상·글자 크기는 실제 카카오톡 캡처(안드로이드 스크린샷, 아이폰 화면 녹화)를 픽셀 단위로 측정한 값(`src/lib/kakaoSpec.ts`)을 사용합니다.
`/dev/preview`(개발 모드 전용)는 기준 스크린샷과 같은 대화를 그려서 비교할 때 씁니다.

## 기술 스택

- Next.js (App Router) + TypeScript + Tailwind CSS
- Prisma + SQLite (사진도 base64로 DB에 함께 저장)
- 글꼴: Pretendard (SIL OFL, `public/fonts`)

## 시작하기

```bash
npm install
npx prisma migrate deploy   # DB 생성/업데이트
npm run dev
```

`.env`의 `DATABASE_URL`에 SQLite 파일 경로를 지정합니다 (예: `file:/절대/경로/prisma/dev.db`).

## 빌드

```bash
npm run build
npm start
```
